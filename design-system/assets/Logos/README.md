# Logos

The Satanen mark: "100" in rounded teletext mosaic blocks, one section colour per digit (#86A6FF, #6DD27C, #F2A35E) on graphite #15181D.

- `satanen-icon.svg`: the iOS app icon and the in-app mark (rounded tile).
- `satanen-icon-android.svg`: Android adaptive icon foreground with background, mark sized for the round safe zone.

Use only on its own graphite tile. Minimum size 24px; no wordmark below that.
