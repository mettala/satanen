# LeadCard

The front page's top story: a `surface` card with SectionLabel, `lead` headline and a two-line ingress.

- Padding `space-4` + 2px; radius `radius-lg`; no shadow, no border.
- Ingress in `body-sm` / `ink-muted`, cut to 3 lines.
- Only one LeadCard per screen. The lead is the first story of page 100.
