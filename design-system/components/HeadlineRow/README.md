# HeadlineRow

One tappable story in a section list: headline left, page number right, hairline above.

- Headline in `headline` / `ink`; page number in `meta` / `ink-muted`, tabular figures, baseline-aligned.
- 1px `line` border on top; vertical padding 10px; whole row is the tap target (min `touch`).
- Lists group rows under a SectionLabel. The first row of a group keeps its top hairline.
