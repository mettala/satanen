# SectionLabel

An uppercase section name with an 8px dot, in the section's colour, optionally followed by a page number or time.

- Style `label`; colour = the section token (`section-news` …, `section-other` for uncoloured sections).
- Dot is `dot` size, same colour. Separator is " · ".
- Use above each front-page section, above the lead story and article title, and in favourite cards.
- Never colour the headline itself; only the label carries the section colour.
