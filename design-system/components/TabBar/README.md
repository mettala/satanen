# TabBar

Bottom navigation with four tabs: Uutiset, Urheilu, Sää, Suosikit.

- 24px outline icon over a `tab` label; inactive in `ink-muted`.
- The active tab takes its section colour (Uutiset `section-news`, Urheilu `section-sport`, Sää `section-weather`, Suosikit `ink`).
- 1px `line` on top, `bg` background, safe-area padding below. Each tab is at least `touch` tall.
- All other sections live in the ☰ drawer, not here.
